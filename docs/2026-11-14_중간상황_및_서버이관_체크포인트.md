## 4. 서버 저장공간 규칙 (`/ws` NVMe SSD vs `/hdd` 1TB HDD)

- **컨테이너 `/` 루트 내부에 대용량 데이터·로그 저장 금지** (호스트 루트 SSD 여유 공간 보호).
- **`/ws` (NVMe SSD):** 소스 코드, ROS 2 `colcon build`, 실시간 학습 중인 최신 체크포인트/버퍼 등 고속 I/O 작업 전용.
- **`/hdd` (1TB 전용 HDD):** 대규모 학습 아카이브 체크포인트, TensorBoard 장기 로그, `rosbag2` 데이터, 대규모 시뮬 데이터셋 저장 전용.

### Phase 2. Tesla V100 (32GB) 기반 대규모 · 장시간 강화학습 (약식 학습 금지)

1. **목표:** 기존 메모리리스 TD3(`collapsed_heavy` 20%) 한계를 극복하고, 복잡한 붕괴·협소·동적 환경에서 일반화 성능이 검증된 고성능 회피·복귀 RL 정책 학습.
2. **필수 학습 원칙:**
   - **충분한 대규모 학습:** 수백 에피소드 약식 테스트로 끝내지 말고, 최소 **10,000 ~ 50,000+ 에피소드(또는 수백만 타임스텝)** 규모로 수렴할 때까지 장시간 학습을 돌린다.
   - **커리큘럼 학습 + 도메인 무작위화:** 기본 회피 → 고밀도 다중 낙석/막다른 골목 → 동적 이동 장애물 + 바퀴 슬립/LiDAR 노이즈·지연 순으로 난이도를 높여 누적 학습한다.
   - **시계열·공간 인식 입력:** 단일 프레임 LiDAR만 쓰지 않고 **다중 프레임 이력(Frame Stacking / GRU·LSTM)** + 로컬 코스트맵 + 변위/정체 상태 피처를 반영한다.
   - **미학습 시드 검증 기준:** 학습에 쓰지 않은 **50개 이상 미학습 시드(Unseen Seeds)** 에서 목표 성공률(예: `≥ 95%`)이 안정적으로 나올 때까지 보상·하이퍼파라미터를 반복 튜닝한다.
   - **Teacher(V100) → Student(ONNX) 증류:** V100에서 학습한 대형 Teacher(PPO/SAC)를 소형 온보드에서도 실시간(`10~30 Hz`) 동작하는 경량 **Student ONNX** 로 증류해 `2D A*` 하이브리드와 통합 검증한다.
   - **저장 위치:** 실시간 `best`/`last` 체크포인트는 `/ws`에 두고, 백업 스냅샷·TensorBoard 장기 로그·대규모 에피소드 데이터는 `/hdd`에 보관한다.
