### `house` 직전 잔여 실패 2건(`#04`, `#07`) 원인 분석 기록
- **`#04` (`err=178.83cm`, `242.4s`):** 복도 낙석 `[0.011, 0.389]` 아래쪽 약 `0.28~0.31m` 틈새가 `0.05m` 격자 + `0.10m` 팽창에서 닫혀 `[-0.345, 0.177]`에서 진동 → `0.04m / 0.085m` 정밀화로 해결.
- **`#07` (`err=836.22cm`, `350.1s` 타임아웃):** 남동쪽 방 `cafe_table` `(6.359, -3.192)`의 바닥 `0.56×0.56m` 받침대(`z=0.02~0.04m`, `x=6.079~6.639`)가 2D LiDAR 평면(`z≈0.17m`) 아래에 있어 바퀴가 모서리(`[5.974, -3.019]`)에 반복 걸림 → `_virtual_obstacles` 가상 접촉 장벽으로 해결.

## 4. 앞으로 수행할 남은 시뮬레이션 계획 (서버 PC 실행 절차)

서버(Ubuntu 22.04 LTS Docker + ROS2 Humble 권장)에서 저장소를 클론/풀 받은 뒤 아래 순서대로 실행합니다. (단일 Gazebo 실행은 RTF `4.0` 요청 시 CPU 단일 코어 성능에 비례하며, 중단 시 `--resume`을 붙이면 완료된 trial을 건너뛰고 이어서 실행합니다.)

### Step 0. 환경 빌드 및 단위 테스트 확인
```bash
source /opt/ros/humble/setup.bash
cd ~/disaster_recovery_ws
colcon build --packages-select disaster_recovery
source install/setup.bash
python3 -m pytest -p no:anyio src/disaster_recovery/test
```

### Step 1. `[4/5] house` 최신 코드 10회 검증 (`--reuse-baseline`)
> 로컬에서 이미 완료된 `ab_house_10trials.json` 최종 결과를 추가로 덮어쓸 필요가 없다면, 서버에서는 Baseline이 이미 고정된 상태에서 Proposed만 검증합니다.
```bash
python3 scripts/host/ab_disaster_benchmark.py \
  --scenario house --trials 10 --rtf 4.0 --seed 2026 --reuse-baseline \
  --out-dir benchmark_results/ab_comparison
```

### Step 2. `[5/5] maze` 업그레이드 `MAZE_ROUTES` 10회 A/B 신규 실행 (`BASELINE` + `PROPOSED`)
> 구버전 얕은 `maze` 결과를 업그레이드된 다구간 미로+동적 장애물 시나리오로 전면 교체합니다.
```bash
python3 scripts/host/ab_disaster_benchmark.py \
  --scenario maze --trials 10 --rtf 4.0 --seed 2026 \
  --out-dir benchmark_results/ab_comparison
```

### Step 3. 기존 3대 환경(`collapsed`, `collapsed_heavy`, `tunnel`) 최종 코드 일괄 재검증 (`--reuse-baseline`)
> 저장된 `BASELINE` 및 고정 낙석 좌표를 그대로 재사용하여, 5개 시나리오 전체(50쌍)가 **단일 최신 빌드** 기준으로 공정하게 정렬되도록 합니다.
```bash
python3 scripts/host/ab_disaster_benchmark.py \
  --scenario collapsed --trials 10 --rtf 4.0 --seed 2026 --reuse-baseline \
  --out-dir benchmark_results/ab_comparison

python3 scripts/host/ab_disaster_benchmark.py \
  --scenario collapsed_heavy --trials 10 --rtf 4.0 --seed 2026 --reuse-baseline \
  --out-dir benchmark_results/ab_comparison

python3 scripts/host/ab_disaster_benchmark.py \
  --scenario tunnel --trials 10 --rtf 4.0 --seed 2026 --reuse-baseline \
  --out-dir benchmark_results/ab_comparison
```

### Step 4. 그래프 재생성 및 최종 보고서 업데이트
```bash
python3 scripts/host/plot_ab_comparison.py \
  --in-dir benchmark_results/ab_comparison \
  --out-dir docs/images
```
